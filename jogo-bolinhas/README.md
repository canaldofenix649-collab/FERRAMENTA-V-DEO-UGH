# Liga das Bolinhas

Jogo de futebol de bolinhas para celular, com modo carreira: Séries A, B e C, estaduais, Copa do Brasil, Libertadores, Sul-Americana e Mundial.

## Como jogar no celular

Abra o `index.html` no navegador. O progresso fica salvo no próprio aparelho.

## Instalar como aplicativo

Hospede esta pasta em um endereço HTTPS (por exemplo, GitHub Pages). Ao abrir pelo celular, use "Adicionar à tela inicial". O jogo ganha ícone próprio e passa a abrir sem internet depois da primeira visita (`manifest.webmanifest` e `sw.js`).
